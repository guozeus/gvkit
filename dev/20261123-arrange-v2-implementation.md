## 协议与迁移

`settings/gvkit/arrange-v2/activation.md` 同一不可变文件包含 epoch、完整初始配置及旧配置原文。发布执行者通过已有 Vault 工具仅创建一次；客户端绝不因未见文件再建基线。设备收到前仅显示旧可信数据、独立事项可继续完成；收到后只用 v2。已采用的基线和操作有设备本地副本，晚到坏 YAML 不再参与新版权威。

每条修改一个只创建不重写的 Markdown 文件，正文是封装 JSON；按字段前置及操作 ID/逻辑业务键重建投影。本机先耐久保留 ID 和原字节，再创建共享文件并逐字读回；未知结果沿原 ID 重试。本机保存不声称远端已同步。偏好独立字段、每日达成按天、排序按移动意图；每日目标返回和排序同一操作。业务去重键为 epoch+动作+业务日；提醒可依赖跨天逻辑键，而非某设备物理操作 ID。

旧格式没有可证明修改时间/因果，仅字节合法且不同于基线不代表新意图。因此迟到旧修改不自动覆盖 v2，原件保留。恢复应保留 activation、ops 及设备本地待发送记录，使用能读 v2 的修正版；不能直接降级为旧 YAML 快照。
